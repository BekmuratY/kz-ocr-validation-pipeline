# Final Report: Kazakhstan License Plate Recognition (Local, Open Source)

## 1. Task Goal

Implement a local, open-source pipeline that:
1. Uses a dataset of 100 car images.
2. Processes/annotates data for plate recognition.
3. Trains a model on this dataset.
4. Runs Python inference to detect a plate and convert it to text.

All components are executed locally on the computer, with an offline/mobile deployment direction.

## 2. Project Data

- Source images: `data/cars/` (100 images, Kazakhstan plates).
- Dataset structure used for training:
  - `data/kz_plate/images/{train,val,test}`
  - `data/kz_plate/labels/{train,val,test}`
  - `data/kz_plate/data.yaml`
  - `data/kz_plate/ocr_labels_template.csv` (ground-truth plate texts).

Current split:
- train: 70
- val: 20
- test: 10

## 3. Implemented Pipeline

### 3.1 Data preparation
- Script: `scripts/prepare_dataset.py`
- Creates YOLO-compatible structure and initial OCR template CSV.

### 3.2 Bounding-box annotation
- Semi-auto annotation script: `scripts/semi_auto_annotate.py`
- Manual fallback: `scripts/annotate_bboxes.py`
- All 100 images were annotated with plate bounding boxes.

### 3.3 Detector training
- Script: `scripts/train_detector.py`
- Model: YOLOv8n (Ultralytics, open source).
- Output weights: `runs/detect/.../weights/best.pt`

### 3.4 OCR and postprocessing
- Script: `scripts/infer_plate.py`
- OCR backend:
  - PaddleOCR (primary)
- Postprocessing includes:
  - normalization of OCR output,
  - `KZ` prefix/suffix cleanup,
  - KZ plate format correction (common confusions like `8<->B`, `1<->I` by position),
  - format and region validation,
  - confidence-like postprocess score.
Additional output:
- `plate_type` (NEW_STANDARD / OLD_STANDARD / DIPLOMATIC / TRANSIT / TRAILER / INVALID).

### 3.5 Batch and evaluation tooling
- Batch inference: `scripts/batch_infer.py`
- OCR evaluation (Exact Accuracy + CER): `scripts/evaluate.py`
- Model export for mobile/offline: `scripts/export_model.py`
- Unit tests:
  - `tests/test_postprocess.py`
  - `tests/test_validation_rules.py`
  - `tests/test_batch_contract.py`

## 6. Offline/Mobile Deployment Direction

1. Export detector:
```bash
pip install onnx onnxruntime
python3 scripts/export_model.py --weights runs/detect/plate_kz/weights/best.pt --format onnx --imgsz 640
```
or
```bash
python3 scripts/export_model.py --weights runs/detect/plate_kz/weights/best.pt --format tflite --imgsz 640
```

2. Use local OCR models by setting env vars (no network):
- `PADDLEOCR_TEXT_DET_MODEL_DIR`
- `PADDLEOCR_TEXT_REC_MODEL_DIR`
If set, missing paths will raise an explicit error at startup.

3. Reuse the same normalization/validation logic from `scripts/infer_plate.py` on device.

## 8. Limitations and Improvement Plan

Limitations:
- strong tilt/motion blur,
- very small plate region in the frame,
- night/backlight glare, dirt/occlusion,
- rare or non-standard plate layouts.

Priority improvements:
- expand dataset with more low-light, rainy, and low-resolution cases,
- add augmentation focused on blur, glare, and resolution loss,
- consider OCR fine-tuning on KZ-specific plates.
